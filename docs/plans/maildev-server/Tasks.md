# Tasks: MailDev Server

All implementation tasks below are **planned**. IDs and REQ/AC IDs are scoped to `maildev-server`. User confirmed phase 1 capture/inspection and local POP3 server, then required phase 2 real SMTP/API delivery after phase 1 works and is accepted. The selected DB stores full raw MIME, including allowed encoded attachment duplication; extracted decoded attachments live in the selected Volume/S3/Azure Blob backend. Direct MX versus smarthost and deployment authorization remain open; upstream POP3 polling is outside confirmed scope. This plan does not authorize sending real email or establishing external cloud accounts. Dependencies on the unimplemented [.NET platform tasks](../dotnet10-platform/Tasks.md) are explicit; earlier QA/SEC reports are historical and documentation review is separate from runtime acceptance.

PM updates status and records user decisions. Phase 2 delivery is required after phase 1 acceptance; upstream polling and UI task dependencies activate only when separately approved; all tasks are future implementation tasks, not work completed by writing this plan.
